# Project page: Exploring Visual Representations for World–Action Models

Static site (no build step), modeled on unbundling.github.io: every chart is SVG drawn by `static/js/viz.js`
from the numbers in `static/js/data.js`, which copy the technical report's tables and figure records.

Preview: `python3 -m http.server 8765` in this folder, then open http://127.0.0.1:8765/.
